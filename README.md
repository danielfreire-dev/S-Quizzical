## How It's Made:

**Tech used:** HTML, CSS, JavaScript, React.js

This project was designed to be efficient, mantainable and scalable web apps from the start. With this in mind, React.js was chosen for its development.

## Optimizations

- Better separation of functions
- Provide a special celebration if the user answers correctly to all questions.
  - Even more special celebration if the user answers correctly 50 questions(maximum amount of questions).
- Keep history of games
- Make the project WCAG compliant

## Lessons Learned:

I learned many lessons whilst working on this project.
This project started out of a personal passion for Trivia games. I am always looking for ways to use my Web Development knowledge to share my passions with the world, and as soon as I learned about the [Open Trivia Database](https://opentdb.com) I knew I had to build such a project.
